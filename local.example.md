# Local settings (example)

Copy this file to `local.md` next to `SKILL.md` (folder install), or to
`~/.claude/design-divergent.local.md` (plugin install). `local.md` is ignored by git:
put there what only applies to you. The skill reads it first and it overrides
the defaults.

## Language and file names

- Language to talk in, tone rules.
- File names of the divergence folder if you want them in another language.

## Your own hard constraints

- Your design system, and what may never diverge (palette, type, logo).
- Third-party tools or options you do not want used on your deliverables.

## Run log

- Where to keep a private log of your runs (paths, verdicts word for word).
